# NJ-in-Element
It is my very own personal website that gives a sneak peak into my interests and things I have done in these past few years.

## What's Inside(The pages)

- **My Art**: Click to expand and view my full artwork with descriptions.
- **Projects**: Showcase of my coding and robotics work.
- **About Me**: My personal bio and a bit about me.

## Features

- Interactive modal galleries (click images to expand).
- Welcome pop-up screen on the homepage every time you open it.
- Smooth animations and hover effects.
- Clean, responsive design.

## Tech Stack
HTML, CSS and Javascript(no dependencies used)
